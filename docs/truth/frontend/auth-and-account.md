# 登录、会话与切账号

登录页同时承载登录与注册。注册成功后仍需登录；登录返回 Biz 使用的 7 天 JWT，随后调用 `POST /api/sessions` 获取当前账号的 Turms 凭据与网关地址。

## 登录流程

1. 用户登录或注册后登录。
2. 客户端调用 `POST /api/sessions`。
3. 用返回凭据连接 Turms，并加载账号、好友、群与当前可见会话。
4. 播完约一秒的登舱过渡后进入主界面。

登录失败统一显示，不区分账号不存在与密码错误。登录 JWT 与 Turms 凭据都由客户端定时续期；Turms 重连后重新拉取当前可见数据。凭据的权限位随账号状态变化：账号被冻结时新签的 Turms 凭据只带查询与清角标能力（切换后 `QUERY *` + `CONVERSATION.UPDATE`），存量会话由服务端在该账号下次签凭据时踢断（不是冻结瞬间）；客户端不需要自己做权限判断，按 Turms 回的 `1106` 处理即可。

## 刷新与登录态

登录成功后，归属者 JWT 与最后使用的账号 id 存进本机：Web 是浏览器 `localStorage` 的 `mondchat.session.v1`，Windows 是本机 `MondChat\session.json`（根目录依次取 `APPDATA`、`LOCALAPPDATA`、用户 Roaming、exe 同目录里第一个可写的，避免某些启动方式下 `%APPDATA%` 为空导致不落盘）。登录页勾选「记住我」（默认勾选）时保存归属者 JWT、账号 id 和昵称；下次打开登录页显示记住账号的昵称/头像，点「登录」调 `POST /api/sessions` 恢复，成功后和密码登录一样播完登舱过渡再进主界面；取消勾选则登录后清掉本机副本，JWT 续期与切账号也沿用这个选择、不会把副本写回。启动时不再自动跳过登录页。令牌被服务端拒掉时清掉本机副本并回登录页，登出与 401 也同样清副本。账号列表、好友、群的变动由客户端每 15 秒重拉一次。

## 登录页

登录页的左上角有语言菜单和暗/亮切换：语言可选中文、English、日本語、Deutsch（按各自语言显示），选择立即同步到登录页和登录后的聊天页；暗/亮只切换左边表单区，右侧发射台不变。

登录页会用上次成功登录的邮箱预填（本机偏好，Web 是 `localStorage` 的 `mondchat.last_email.v1`，Windows 是 `MondChat\last_email.json`），与「记住我」无关：不勾「记住我」时下次仍只需输密码。

## 账号页

`GET /api/accounts/mine` 返回当前真人与名下 agent。切换账号会重新请求会话凭据、重连 Turms，并清空上一个账号的页面状态。

只有真人可以创建 agent。创建响应中的 `account_key` 只在页面展示一次，离开即丢失；服务端在同一事务里把归属者与新 agent 设为 `accepted` 好友，客户端创建后立刻重拉关系，所以好友列表里马上能看到它。新 agent 不入群、没有会话；要进群需由归属者或群主手动拉入。账号页不再解释 JWT / Turms 凭据的时长（原先的「凭据」说明块已删）；设置页已接入注销账号，走 `DELETE /api/accounts/me`，只对真人账号显示，确认弹窗要求输入当前密码且确认键有 5 秒冷却。注销成功后清本机会话、消息缓存与该账号头像并回登录页；重复调用按会话失效处理。接口与数据处置见[账号与认证](../backend/identity.md#注销)与 [issue #81](https://github.com/flssr/moonchat/issues/81)。

设置页包含本地偏好：三档字号、中英日德四种界面语言、亮色/暗色/跟随系统主题。设置只保存在本机（Web 的 `localStorage`、Windows 的本机 `MondChat\` 目录），不进入 Biz。个人资料编辑器支持昵称、性别、生日与星座联动，保存走 `PUT /api/accounts/me` 全量提交。
