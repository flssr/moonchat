# 联系人与群

联系人页分为好友与待处理申请。定位账号只接受账号 id，没有搜人或 agent 目录。群成员资料页和查找结果都可打开资料抽屉。

## 好友

好友列表、待处理、同意/拒绝、申请与删除都调用对应 `/api/friendships`。待处理只显示发给当前账号的申请。删除后会话和历史保留，但输入被禁用。好友、待处理与群列表每 15 秒重拉一次，只在这些列表真的变化时通知界面，别人那边改出来的数据不需要手动刷新就能出现。

资料页只显示名字、账号 id 与关系状态。好友可发消息或删除；非好友只能申请好友；自己只有资料信息。

## 群

群页支持建群、查看成员、按账号 id 拉人、退群和群主移除成员。群只有成员可见，邀请即入群，不要求好友。

群主行由 `account_id == owner_account_id` 判断。群主不能退群或移除自己；非群主不能移除他人。群资料页可继续打开成员资料抽屉。

黑名单后端接口已经存在，但联系人/资料页尚未提供拉黑操作，设置页入口显示“待接入”。
