# 联系人与群

联系人页分为好友与待处理申请。定位账号接受短号或完整账号 id，没有搜人或 agent 目录。群成员资料页和查找结果都可打开资料抽屉。

界面把 `account.id` 折成从 1 起的短号展示（`100000000 → 1`、`100000001 → 2`……），加好友/拉人输入框接受短号或完整 id；API 和 Turms 仍用完整 id。短号只是显示约定，依赖后端 identity 从 1 亿起，后端改起点时 `lib/account_id.dart` 要同步。

## 好友

好友列表、待处理、同意/拒绝、申请与删除都调用对应 `/api/friendships`。待处理只显示发给当前账号的申请。删除后会话和历史保留：双方都不收到删除通知，私聊会话按本地历史留在列表里；再发送时客户端提示「当前不是对方好友，请添加后再进行会话」——**当前**后端不投递，**切换后**由 Turms 按投影后的关系拒绝（`5001`）。删除确认里可选「删除并拉黑」，被拉黑方无法再主动加回来。好友、待处理与群列表每 15 秒重拉一次，只在这些列表真的变化时通知界面，别人那边改出来的数据不需要手动刷新就能出现。

资料页点「加好友」成功后按钮变「已申请」并禁用，换一个账号或重新搜索时复位；被加的一方点「同意」后，客户端自动给对方发一条「我们已经是好友啦，一起来聊天吧OWO」，发送失败不回滚好友关系。

资料页只显示名字、短号与关系状态。好友可发消息、删除好友或拉黑/取消拉黑；黑名单走已有 `/api/blocklist`，拉黑只做关系标记，消息拦截**当前**由 Biz 负责、**切换后**由 Turms 按投影判定。非好友只能申请好友；自己只有资料信息。

## 群

群页支持弹窗建群（群名 ≤20 字 + 可选简介 ≤200 字 + 从好友多选邀请）、查看成员、成员列表底部「+」从好友邀请（按好友短号搜索，非好友提示「无此好友」）、退群和群主移除成员。群简介 `room_info.description` 只在建群时写，`GET /api/rooms/{roomId}` 返回；群资料右栏在「群 {id} · {m} 人」下面把它显示成一个浅底卡片，没有简介就不占位。群只有成员可见，邀请即入群，不要求好友。

群主行由 `account_id == owner_account_id` 判断。群主不能退群或移除自己；非群主不能移除他人。群资料页可继续打开成员资料抽屉。

拉黑是单向关系标记：资料页可拉黑/取消拉黑；设置 → 隐私 → 黑名单管理打开列表弹窗（`GET /api/blocklist`，一次取到上限 100 人），每行「解除」走 `DELETE /api/blocklist/{accountId}`。被我拉黑的人不再出现在聊天界面的会话列表里（`AppState.conversations` 过滤 `dm:` 会话），解除后自动回来；联系人页与好友关系不变——拉黑不删好友。
