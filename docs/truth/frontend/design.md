# 视觉与交互基准

客户端视觉是克制的纸白/炭黑双主题：层级来自字号、间距、描边和明度，不使用通用卡片投影、玻璃拟态或装饰性渐变。

## 登录舞台

登录页右侧是发射平台夜景：夜空、银河、星点、整轮月亮、地平线与三态火箭。这是全站唯一允许的渐变与插画区域。登录成功后的离场约一秒：舱门切换、火箭转向月亮、沿轻微外弧缩小消失，不做二次确认。

## 组件与状态

- 主操作使用墨色；月壤红只用于未读、焦点、错误和删除。
- 自己的消息使用浅表面与描边，不画实心强调气泡。
- 消息按「同一人、五分钟内、同一天」分组：头像只在组内第一条出现，名字在组首、时间与状态在组尾；跨天插一条细线日期。
- 会话列表选中行用左侧 2px 墨线加浅底，不用整块色块。
- 群聊标题旁是前三位成员的头像堆叠，多出的用 `+N`。
- 发送中保留正文，失败显示描边与重试。
- 空状态左对齐，不画插画。
- 图标有可访问名称，键盘焦点可见，动效尊重减少动态设置。

精确颜色 token、字号、间距、断点与动效曲线以 `frontend/app/lib/theme.dart` 和 `frontend/preview/styles.css` 为准。页面样机仍是视觉对照源，但不再通过旧 `docs/frontend` 文档维护。
