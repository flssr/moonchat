# MoonChat 客户端设计规范 v1

- 状态：评审通过，作为 Flutter Web 还原基准
- 日期：2026-11-11
- 页面：`frontend/preview/index.html`
- 行为依据：`docs/goal-and-requirements.md`、`docs/api-contracts.md`
- 视觉基线：Moonchat-UI.zip（火箭三态插画沿用原资产）

这份规范只描述页面里已经实现的样式。页面没有的组件不在这里定义。

## 1. 设计原则

1. 背景只有纸白和炭黑两种。星云、渐变、玻璃拟态、卡片投影都不使用；`box-shadow` 只用于焦点环与输入外环。
2. 主操作只用墨色。月壤红只给未读、焦点环、错误、删除。
3. 层级靠字号、间距、描边和明度，不靠颜色和阴影。每屏只有一个视觉焦点。
4. agent 与真人同形。资料页不标注来源，来源只进服务端日志。
5. 动效只解释状态变化，不做装饰循环，不做滚动淡入。

### 对比度（已实测）

| 前景 | 落点：bg / surface / surface-2 / stage / 气泡 | 结论 |
| --- | --- | --- |
| 亮 `--ink-3` | 5.21 / 5.59 / 4.76 / 4.55 / 4.95 | 全部 ≥ 4.5 |
| 暗 `--ink-3` | 5.50 / 5.17 / 4.67 / 5.22 / 4.78 | 全部 ≥ 4.5 |
| 亮 自己消息文字 | 14.2 | 远超 AA |
| 暗 自己消息文字 | 13.2 | 远超 AA |

月相线与地平线用 `--ink-3`，亮色 4.55、暗色 5.22；不做透明度衰减（地平线透明度 0.85）。月盘填充 `--surface-2`。

## 3. 字体

字体栈不加载网络字体：

```
--sans: "Segoe UI Variable Text", "Segoe UI", "PingFang SC",
        "Hiragino Sans GB", "Microsoft YaHei", system-ui, -apple-system, sans-serif;
--mono: ui-monospace, "Cascadia Mono", "SF Mono", Consolas, "Liberation Mono", monospace;
```

| 角色 | 字号 / 行高 | 字重 | 说明 |
| --- | --- | --- | --- |
| 封面标题 | clamp(42px, 5.4vw, 68px) / 1.06 | 400 | 字距 -0.035em |
| 章节标题 | clamp(28px, 3.4vw, 40px) / 1.18 | 400 | 字距 -0.025em |
| 导语 | 17px / 1.75 | 400 | 最大 54ch |
| 正文 | 15px / 1.68 | 400 | 全局基准 |
| 小标题 | 16px | 600 | 面板、卡片 |
| 注释 | 12–12.5px / 1.65 | 400 | `--ink-3` |
| 等宽标记 | 10–11px | 400 | 大写、字距 .10–.12em |
| 应用标题 | 14.5px | 600 | 会话头部 |
| 消息正文 | 13.5px / 1.6 | 400 | 气泡内 |
| 列表副行 | 11.5px | 400 | 会话预览 |
| 时间 / ID | 10px mono | 400 | 账号 ID 可选中 |
| 密钥 | 12px mono | 400 | 一次性展示 |

中文不额外加字距。数字统一用等宽字。

## 4. 间距、圆角、描边

- 间距只取 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 圆角只取 `--r1: 4px`、`--r2: 8px`、`--r3: 12px`、全圆 `999px`。气泡靠人一侧的下角用 4px。
- 描边统一 1px；控件外框 `--line-strong`，内部分隔 `--line`。
- 章节上下留白：桌面 88px，≤900px 时 56px。
- 页面左右留白：桌面 56px，≤1080px 32px，≤900px 20px。

## 5. 布局与断点

| 区域 | 桌面 | 收窄后 |
| --- | --- | --- |
| 页面壳 | 左侧 236px 固定栏 + 正文 | ≤900px 顶栏，隐藏栏内说明 |
| 登录样机 | 44% 表单 / 56% 舞台，min-height 540px | ≤900px 上下排列，舞台 min-height 300px |
| 客户端样机 | 56px 导航 + 252px 会话 + 自适应 + 236px 信息，高 620px | 容器 ≤860px 收起信息栏；≤620px 收起会话栏，改用列表按钮，高 560px（页面 ≤560px 时 520px） |
| 联系人 / 账号 | 320px 列表 + 自适应详情 | ≤620px 上下两段，详情可滚动 |
| 资料页 | 右侧抽屉，宽 min(352px, 88%) | 同左 |
| 产品断点 | 1080 / 900 / 560（页面） | 组件断点用容器查询 860 / 620 |

页面不是营销落地页，正文最宽约 1092px，不要加居中大标题或满屏英雄区。

## 6. 组件

### 按钮

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| 主要 | `--ink` 底，`--bg` 字，1px 同色边 | 每屏一个主操作 |
| 次要 | 透明底，`--line-strong` 边，`--ink` 字 | 资料页、对话框 |
| 文字 | 无底无边，`--ink-2` 字 | 辅助动作 |
| 危险 | 透明底，`--accent` 边与字 | 删除好友、移除成员 |
| 小号 | 高 30px，12px 字 | 列表头、行内动作 |
| 禁用 | 透明度 .4，不可点 | 表单提交中 |

高度 40px，内边距 0 18px，圆角 8px。悬停只改边框或透明度，不位移。

### 输入

- 容器：1px `--line` 边，圆角 8px，内边距 8px 12px 7px，透明底。
- 标签：10px 等宽大写，`--ink-3`。
- 输入文字：14px。
- 悬停：边 `--line-strong`。
- 焦点：边 `--ink-2` + `0 0 0 3px var(--accent-soft)`；组件样例用 `.field.is-focus` 复用同一组样式。
- 错误：边 `--accent`，下方 11px 错误文案，`aria-invalid="true"`。
- 占位符：`--ink-3`。

### 消息气泡

- 圆角 12px，靠人一侧下角 4px，内边距 9px 13px，最大宽 min(72%, 460px)，正文 13.5px。
- 对方：`--bubble-them` 底 + `--line` 描边。
- 自己：`--bubble-me`（即 `--surface-2`）底 + `--line` 描边，文字 `--ink`。
- 时间：气泡外，10px 等宽，`--ink-3`。
- 状态：
  - 发送中：保留正文，时间位显示“发送中…”。
  - 已发送：时间位显示 HH:MM。
  - 失败：红色描边气泡 + “重试”文字按钮。
- 组件卡与实际样机必须一致：不画 spinner，不画无正文的“发送中”。

### 列表与标记

- 会话行：约 52px 高，34px 单字头像，1px 描边；选中用 `--surface-2` 底，不用发光边框。
- 未读：16px 圆形红底数字，只有未读才出现；不叠状态点。
- 关系标记：20px 高、全圆、1px 描边；`群主` 描边 `--ink-2`，`待处理` 用 `--ink-3`。
- 账号 ID：10–11px 等宽，可选中复制。
- 密钥：12px 等宽整行展示，只出现一次；旁边是复制图标按钮。

### 空状态

- 左对齐，最大 38ch，不画插画，不用居中大标题。
- 一句标题 + 一句解释 + 一个可选主操作。
- 覆盖：无会话、无好友、无待处理、无匹配结果、非好友资料页。

## 7. 动效

| 场景 | 时长 | 缓动 | 内容 |
| --- | --- | --- | --- |
| 悬停、按下、发送状态 | 120ms | standard | 底色、描边、透明度 |
| 主题切换、弹层 | 200ms | standard | 颜色与透明度 |
| 会话切换、资料页 | 320ms | standard | 淡入 8px；资料页从右移入 16px |
| 登录表单收束 | 420ms | standard | 表单淡出并上移 6px；不飞入舱门 |
| 舱门 | 180ms | standard | 插画“开启 → 关闭”交叉淡入；不做第二次确认 |
| 离地 | 620ms | ease-out | “关闭 → 点火”后上移 56px、缩到 .94、淡出 |
| 抵达 | 200ms | standard | 主界面或抵达卡淡入 |

- standard：`cubic-bezier(.2, .7, .2, 1)`
- ease-out：`cubic-bezier(.16, 1, .3, 1)`
- 登录过渡总时长约 1 秒。登录是高频动作，超过 1 秒会被当成等待；不做编号字幕、白光、旋转和飞出画面。
- 不使用回弹、无限循环、视差、滚动淡入。
- `prefers-reduced-motion: reduce`：所有过渡与动画压到 0.01ms；登录过渡直接跳到终态。

## 8. 主题

- 初始主题按 `localStorage.moonchat-theme`，没有则跟随系统。
- 切换点：页面左下角按钮 / 移动端顶栏图标；写入 localStorage。
- 预览参数：`?theme=light`、`?theme=dark` 强制主题，不写存储。
- 切换只改变量，不改变布局；过渡 200ms，只作用于颜色相关属性。

## 9. 可访问性

- 键盘焦点环：2px `--accent`，`outline-offset: 2px`，只在 `:focus-visible` 出现。
- 输入焦点外环：3px `--accent-soft`。
- 正文与次要文字 ≥ 4.5:1；描边只作装饰。
- 点击热区不低于 40×40，移动端 44×44。页面里的图标按钮视觉尺寸是 32×32，实现时用内边距或透明外扩补足热区；列表整行可点。
- 消息区 `aria-live="polite"`；图标按钮都有 `aria-label`；未读同时有数字，在线同时有文字。
- 键盘：Tab 顺序为导航 → 列表 → 消息区 → 输入 → 发送；Enter 发送，Shift+Enter 换行，Esc 关闭资料页/侧栏。
- 减少动态时保留可读性，不依赖动画传达状态。

## 10. 不要做

- 不加渐变背景、玻璃卡、卡片投影、emoji 头像。
- 不给消息加已读回执、正在输入、消息搜索——V1 客户端没有 Turms 写权限，也没有对应接口。
- 不把 agent 做成特殊标签或特殊颜色。
- 不在主按钮之外再放一个红色实心块。
- 不在界面写接口错误码原文。

## 11. 与页面的对照

页面 `frontend/preview/index.html` 是唯一视觉源；本文所有数值取自 `preview/styles.css`。改样式先改页面，再同步本文。评审核对项：颜色 token、字体层级、间距/圆角、组件状态、动效时长、断点。
