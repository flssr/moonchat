### 登录页语言与左侧明暗

2026-11-17 01:17 CET   [2026-11-17 00:17 UTC]

决策：登录页左上角加语言菜单（中文/English/日本語/Deutsch，按各自语言显示）和暗/亮切换；语言走 `MondChatApp._setLanguage`，同步到聊天页；暗/亮只把左边表单包进自己的 `Theme`，右侧发射台保持应用主题。记住我待做。

原因：测试改进 2 的第 7、8 条；只换左边，避免把登录舞台一起改色。

### 账号短号显示

2026-11-16 21:13 CET   [2026-11-16 20:13 UTC]

决策：界面把 `account.id` 折成从 1 起的短号展示（`100000000 → 1`、`100000001 → 2`……），加好友/拉人输入框同时接受短号与完整 id。API、Turms 与后端 id 完全不变。

原因：账号 id 从 1 亿起（后端为避开 Turms 开发档与冒烟号段），用户抄写和口头交换都太长。短号复用既有 identity 基址，零后端改动就能把「展示/定位」这层变短；代价是前端硬编码了 1 亿这个起点，后端改 identity start 时要同步改 `lib/account_id.dart`。服务端权威短码（issue #36）因此不做，issue 关闭。

### 消息列表

2026-11-14 23:20 CET   [2026-11-14 22:20 UTC]

决策：消息区改成「栏式」：左侧固定头像栏（连续消息只在第一条显示头像），同一人五分钟内、同一天的消息并成一组，名字在组首、时间与状态在组尾，跨天插一条细线日期；会话选中行左侧加 2px 墨线；群聊标题旁显示前三位成员头像堆叠与 `+N`。

原因：原来的单条气泡每条都挂时间、没有分组与日期，长会话读起来没有节奏；头像与分组补上「谁在说」的第一层线索，又不引入新的颜色或卡片。

### 产品官网

2026-11-14 19:50 CET   [2026-11-14 18:50 UTC]

决策：官网首屏的星点与流星只在暗色出现，亮色只留月亮；减少动态时星图静止且引言不轮换，没有 JS 时正文直接可见，引言在悬停或聚焦时暂停。

原因：白天的纸面不适合满屏星点，动效只该是暗色的余兴；正文与轮换内容是信息本身，不能因为脚本或偏好被藏起来。

2026-11-14 17:22 CET   [2026-11-14 16:22 UTC]

决策：在 `site/` 增加一页静态产品官网：散文式结构、纸白 / 炭黑双主题，品牌图标与 favicon 复用同一枚 SVG；没有构建与外部依赖。

原因：客户端之外需要一个能直接分享的说明页；视觉沿用客户端的纸白 / 炭黑与细线，不引入第二套语言。

### 登舱动画

2026-11-14 01:00 CET   [2026-11-14 00:00 UTC]

决策：登录离场保持一次确认、约一秒；火箭朝月亮加速并缩小消失，补机身倾角与轻微外弧。

原因：登录是高频操作，过长动画像等待；只保留解释状态变化的动作。

### 登录夜景

2026-11-13 23:31 CET   [2026-11-13 22:31 UTC]

决策：登录舞台改为发射平台夜景，画整轮月亮、银河、星点、地平线与三态火箭。

原因：品牌主视觉集中在一处，主界面继续使用纸白/炭黑和克制组件。

2026-11-11 01:28 CST   [2026-11-10 17:28 UTC]
