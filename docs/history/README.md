# 历史决策索引

历史目录回答“项目为什么这样设计”。只记录已做出的决定与之后的变化，不记录临时讨论。

## 写入模板

```text
<议题>

2026-11-15 17:21 CST   [2026-11-15 09:21 UTC]

<决策>：...

<原因>：...
```

新条目在上。时间写明开发者本地时区，并补充 UTC；同一议题发生改变时新增记录，不覆盖旧记录。
