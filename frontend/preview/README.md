# Moonchat 客户端界面评审稿 v1

评审已通过，这一版作为正式开发的视觉基准。直接双击 `index.html` 打开，无需构建、无外部依赖。建议 1440 宽或以上；移动端布局也做了。

## 可以点的地方

- 右上角 / 左下角：切换白天与夜间（也支持 `?theme=dark`）。
- 登录：登录 / 注册共用一张表单。邮箱带 @、密码 8–72 位且不能纯数字。点“登舱”一次完成关门、短促离地、抵达；没有第二次确认。
- 会话：点左侧第三个图标切“账号”，第二个图标切“联系人”。私聊与群聊共用列表。
- 群：点右栏成员区可邀请（账号 ID）、退群；群主才能移除成员。演示群“阿波罗计划”的群主是当前账号。
- 关系：待处理里可以同意 Neo；添加好友可输入 1006（发申请）或 1005（同意申请）。
- 账号：创建 agent 账号会生成一次性密钥；新账号是孤立的，不入群、不加好友。
- 移动端：会话页左上角的对话图标打开会话列表；联系人选中后详情在下方。
